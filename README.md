## Run locally in VS Code

### Option 1 — Live Server
1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

### Option 2 — Direct
Double-click `index.html` and open it in a browser.

## Deploy on Render

This is a static site, so use a Render Static Site.

- Build command: leave empty
- Publish directory: `.`
- Auto-deploy: enabled after connecting the GitHub repository

After deployment, Render will provide an `onrender.com` URL.

## Before publishing

Replace/add any credential or badge URL when you have the exact public verification/profile URL. Do not publish private credential IDs or personal documents unless you intend them to be public.
